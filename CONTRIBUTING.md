# Contribuer à MeetingAI

Merci de votre intérêt pour MeetingAI !

## Processus

1. Forkez le dépôt.
2. Créez une branche dédiée (`git checkout -b feature/ma-fonctionnalite`).
3. Respectez la PEP 8 et Python 3.12+.
4. Assurez-vous que les tests passent.
5. Ouvrez une Pull Request.

## Style de code

- Python 3.12 ou supérieur.
- Suivre la PEP 8.
- Nommer les modules et packages en minuscules.
- Documenter les fonctions et classes publiques.

## Signalement de bugs

Ouvrez une *Issue* avec un titre clair et une description détaillée.
